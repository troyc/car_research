# Source-sensitivity analysis

The former “bias-adjusted” weighting scheme has been retired because its hand-selected multipliers were not a statistical correction for convenience-sample bias.

Use the generated [`ranking_sensitivity.csv`](../data/ranking_sensitivity.csv) for neutral-forum, home-team wins over a different brand excluded (same-brand matchups retained), owner, source, prior, axis, collection-batch, legacy-weight, and thread-cluster scenarios. The main visual summary is [`figures/sensitivity.png`](figures/sensitivity.png); interpretation is documented in [`methodology.md`](methodology.md#sensitivity-analyses).
